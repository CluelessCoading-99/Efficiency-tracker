Excel & CSV Layout Guide

How Your Excel File Must Look

Keep your sheet simple with these 5 columns in order (A–E), using dot (.) decimals and plain numbers.

A: TechnicianB: WIPC: DateD: Requested_HrsE: Given_Hrs
Richard Harrison482912026-11-232.52.5
Richard Harrison483042026-11-231.81.5
Richard Harrison483192026-11-233.0
1. Column A: Must match the technician in Settings. Other names are ignored.
2. Column B: Numeric WIP. Duplicate WIPs in the file have their hours summed.
3. Column C: YYYY-MM-DD, DD/MM/YYYY or DD-MM-YYYY.
4. Columns D & E: Plain decimal numbers (e.g. 1.6). Leave E blank if pending.
5. Save as CSV: File → Save As → CSV (Comma delimited).
Data Safety Guide

How JSON Backup & Restore Works

Your jobs live in this browser. Back up regularly so nothing is lost if cache is cleared.

1. Back Up (Tue & Fri): Click Backup JSON. A file named workshop_backup_YYYY-MM-DD.json downloads.
2. Restore: Settings → Choose File → Restore JSON. Everything returns.
3. Do not edit the JSON file — just keep the newest copy safe.
